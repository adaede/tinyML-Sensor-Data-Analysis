# tinyML Sensor Data Analysis

This project uses TensorFlow Lite for Microcontrollers to analyze real-time sensor data on embedded devices.

## Features
- Sensor data preprocessing
- Feature extraction
- TinyML model training
- Deployment to microcontroller

## Tech Stack
tinyML • TensorFlow Lite • Microcontrollers • Python

## Outcome
Achieved lightweight inference suitable for low-power devices.
